//~~~~~~~~~~~~~~~~~~ ENGLISH LANGUAGE FILE ~~~~~~~~~~~~~~~~~~~~~~~~~~~ 
// Contains all the text in the game in the format of:
// name : value 
// Comments designated with a line start of //
// The \n character designates a line break.
// Anything like {0} or {1} designates a number that will be set in code, and should be left as is. 

// This game can be translated into other latin-based language (sorry, no asian languages supported at this time)
// To use another language with the game copy this file and translate the 'value' (right side) parts.
// Name the file "strung.[language_code].txt"    for example, French would be "strung.fr.txt"
// If your Windows is set to that default language the game will automatically use it. 
// Place the file next to the english file in the "Languages" folder.
// If you have set it up correctly, the language will show up in the options screen.
// v1.09 language file
